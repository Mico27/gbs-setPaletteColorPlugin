# gbs-setPaletteColorPlugin
 Event to set the color of a palette

The value of each color is represented by a 15bit RGB value

"commit" will make the pallette change immediate. If used during a fade-in, uncheck it.

The Copy scene palette colors will copy from another scene palette color data.
Useful when using the submapping plugin and want to submap with the submapped scene color data.
